ferramenta para montar tabelas de transição e entradas JK a partir de sequências de estados.

usar contador usar flip-flop

objetivo

facilitar a construção de tabelas de estados e excitação de flip-flops, automatizando cálculos que normalmente são feitos manualmente.

teoria básica

contadores digitais são circuitos sequenciais que mudam de estado a cada pulso. flip-flops JK permitem controlar essas transições através das entradas J e K.

como usar

  • vá para "contador" ou "flip-flop"
  • digite a sequência de estados
  • clique em gerar
  • visualize a tabela pronta
