sobre

objetivo

gerar automaticamente a tabela de transição de estados e as entradas dos flip-flops JK a partir de uma sequência fornecida pelo usuário.

teoria (resumo)

em circuitos sequenciais, o estado atual (Qn) evolui para um próximo estado (Qn+1). para que essa transição ocorra usando flip-flops JK, é necessário determinar os valores de J e K para cada bit.

Qn Qn+1 J K
000X
011X
10X1
11X0

o sistema considera um ciclo: o último estado volta para o primeiro.

como usar

  1. digite os estados (ex: 2 3 1)
  2. clique em gerar
  3. analise a tabela criada automaticamente
