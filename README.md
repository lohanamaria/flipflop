# Gerador de Tabela JK

Ferramenta web para gerar tabelas de flip-flops JK em contadores da minha iniciação científica na UFABC (2025-2026).

## Uso

### Entrada por bits
1. Escolha o n de bits.
2. Insira 0 ou 1 para cada flip-flop, separados por espaço.
3. Clique em **gerar**.

Exemplo:
q1: 0 0 1 1
q0: 0 1 0 1


### Entrada decimal (contador)
1. Digite a sequência de estados em decimal.
2. Clique em **gerar**.

Exemplo:
0 1 2 3 0

## Tecnologias (até o momento)
HTML, CSS, JavaScript
